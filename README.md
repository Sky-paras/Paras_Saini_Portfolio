# Paras Saini — Portfolio

Personal portfolio website for Paras Saini, Data Analyst & Business Intelligence Developer.

Single-file static site (`index.html`) — no build step, no dependencies to install. All CSS, JavaScript, and the profile photo are embedded directly in the file.

## View it live

Once GitHub Pages is enabled for this repo (see below), the site will be available at:

```
https://sky_paras.github.io/Paras Saini — Portfolio/
```

## How to run locally

Just open `index.html` in any browser — double-click it, or drag it into a browser window. No server required.

## Deploy with GitHub Pages

1. Push this repo to GitHub (see steps in chat).
2. In the repo, go to **Settings → Pages**.
3. Under **Source**, select the `main` branch and `/ (root)` folder.
4. Click **Save**. GitHub will publish the site in a minute or two at the URL above.

## Tech

Plain HTML, CSS, and vanilla JavaScript — Google Fonts (Space Grotesk, Inter, IBM Plex Mono) loaded via CDN link, everything else self-contained.
